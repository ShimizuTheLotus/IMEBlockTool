An simple IME blocking tool. This repository has no more update promised. An improved version is on https://github.com/ShimizuTheLotus/DebrisToys

简单的输入法屏蔽工具，本仓库不再承诺更新。改进版本已合并到 https://github.com/ShimizuTheLotus/DebrisToys

## Known issue | 已知问题

Unable to recover IME when quitting blocked apps in some cases. Fixed in DebrisToys version.

在某些情况下退出禁用输入法的应用时无法恢复输入法状态。在DebrisToys的版本修复了此问题。
